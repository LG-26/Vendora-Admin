# Vendora Admin Dashboard

A modern e-commerce admin dashboard built with Next.js 14, MongoDB, NextAuth, and Tailwind CSS.

## Features

- 🔐 Secure authentication with NextAuth
- 📦 Product management (CRUD operations)
- 📊 Dashboard with stock analytics
- 🖼️ Image uploads via Cloudinary
- 🎨 Modern UI with Tailwind CSS
- 📱 Responsive design

## Getting Started

See [SETUP.md](./SETUP.md) for detailed setup instructions.

### Quick Start

1. Install dependencies:
```bash
npm install
```

2. Set up environment variables in `.env.local` (see SETUP.md)

3. Run the development server:
```bash
npm run dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser

## Tech Stack

- **Next.js 14** - React framework
- **TypeScript** - Type safety
- **MongoDB** - Database
- **NextAuth** - Authentication
- **Cloudinary** - Image storage
- **Tailwind CSS** - Styling
- **Recharts** - Data visualization
